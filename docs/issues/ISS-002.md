## Summary

The daily health check for **LI-002** reported `TOKEN_EXPIRED` on 2026-11-25. Detail recorded by the check: _401 invalid_token: access token expired and refresh token was not rotated_

## Reproduction steps

1. Import the inventory: `npm run cli -- account import --file data/accounts.seed.csv`
2. Run the check for the affected day: `npm run cli -- check run --date 2026-11-25 --account LI-002`
3. Inspect the stored result: `npm run cli -- check history --account LI-002`

**Expected:** account active, connected, token valid, all baseline permissions and assets present.

**Actual:** account_status=`active`, connection_status=`error`, token_valid=`false`, anomalies=`TOKEN_EXPIRED`.

## Likely root cause

## Recommended next action

Re-authorise the account to mint a new token; check why the scheduled refresh did not run.
